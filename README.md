# Paryuktam

Team-based student freelancing & collaboration platform.

## Features

- **Team Formation**: Form teams with fellow students, define roles, and set contribution splits.
- **Real Company Projects**: Work on actual projects posted by companies.
- **Verified Certificates**: Receive auto-generated certificates upon completion.
- **Secure Wallet**: Manage project earnings and payment methods.

## Getting Started

### Prerequisites

- Node.js & npm

### Installation

1. Clone the repository:
   ```sh
   git clone <repository-url>
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```

## Technologies Used

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React (Icons)
